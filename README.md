# 中文医学科普写作技能

维护医学事实已核验后的中文科普表达规则。2026-10-22同步作者新偏好：解释完整、用语自然、论述逐步推进；先写清楚，再删冗余。语言顺畅与事实正确分别审读。

本仓库提供两个独立技能入口，按需要安装对应目录：

| 目录 | 技能 | 适用场景 |
| --- | --- | --- |
| 仓库根目录 | chinese-medical-popular-science-writing | 患者教育、医学科普文章、讲稿与解释材料 |
| skills/chinese-medical-popular-prose-polish | 中文医学科普成书润色 | 成书语体、章节修订与全书语言统一 |
